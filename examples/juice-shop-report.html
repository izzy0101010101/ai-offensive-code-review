Application Overview

Purpose

OWASP Juice Shop is an intentionally insecure web application designed for security training, CTF competitions, and testing security tools. It simulates an e-commerce platform (online juice shop) with user accounts, product catalog, shopping cart, and order processing. The application includes 100+ built-in coding challenges covering OWASP Top Ten and real-world vulnerabilities.

Tech Stack

  • Language: Node.js/TypeScript (backend), TypeScript (frontend)
  • Framework: Express.js (backend), Angular 20.x (frontend)
  • Database: SQLite (file-based via Sequelize ORM)
  • Key deps: jsonwebtoken, helmet, socket.io, multer, pdfkit, ethers/web3, lodash, axios
